## RecipeGenie-AI

An AI-powered recipe generation platform built with Next.js and Tailwind CSS that creates recipes from ingredients or uploaded food images.

## Features

- AI recipe generation
- Generate recipes from food images
- Dynamic recipe detail pages
- Download recipes as PDF
- YouTube recipe tutorials
- Responsive modern UI
- Multiple recipe generation

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- OpenRouter API
- Gemini Vision API
